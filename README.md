# Skybound Obby

A 3D parkour game built with JavaScript and Three.js.

## Overview

Skybound Obby is a browser-based 3D parkour game where players navigate floating platforms, jump across obstacles, collect coins, activate checkpoints, and reach the finish line.

## Features

- **3D Environment:** Colorful floating platforms at different heights.
- **Player Movement:** Move in four directions using keyboard controls.
- **Jump Mechanics:** Jump between platforms to progress through the course.
- **Third-Person Camera:** Follow the player and rotate the camera using the mouse.
- **Coin Collection:** Collect coins and track your score.
- **Checkpoint System:** Save progress at the checkpoint.
- **Lava Hazard:** Avoid falling into the lava below the course.
- **Respawn System:** Return to the latest checkpoint after falling.
- **Finish Detection:** Complete the course to win the game.
- **Restart Option:** Restart the game using the R key.
- **Visual Effects:** Lighting, shadows, fog, and clouds enhance the environment.

## Controls

| Key | Action |
|---|---|
| W | Move Forward |
| A | Move Left |
| S | Move Backward |
| D | Move Right |
| ↑ Up Arrow | Move Forward |
| ↓ Down Arrow | Move Backward |
| ← Left Arrow | Move Left |
| → Right Arrow | Move Right |
| Spacebar | Jump |
| Mouse Drag | Rotate the Camera |
| R | Restart the Game |

*Note: Movement is calculated relative to the camera angle, so the apparent direction on screen may change when the camera is rotated.*

## Technologies Used

- **JavaScript** — Game logic, movement, jumping, collision detection, and scoring.
- **Three.js** — 3D graphics, scene creation, lighting, and camera.
- **HTML5** — Webpage structure and game interface.
- **CSS3** — Interface styling.

## How to Play

1. Start the game and use WASD or the arrow keys to move.
2. Press Spacebar to jump between floating platforms.
3. Collect coins to increase your score.
4. Avoid falling into the lava.
5. Reach the checkpoint to save your progress.
6. Continue along the course and reach the golden finish area to complete the level.

If you fall, you will respawn at your latest checkpoint. Press **R** to restart from the beginning.
